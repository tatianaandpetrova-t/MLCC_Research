# MLCC Recipe Ranking System

Система многокритериального ранжирования рецептур керамической плёнки для производства MLCC-конденсаторов.

## Быстрый старт

### 1. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 2. Подготовка файлов данных

Для работы ноутбуков необходимы следующие файлы (не включены в репозиторий):

| Файл                             | Назначение                                                         | Используется в |
| -------------------------------- | ------------------------------------------------------------------ | -------------- |
| `param_constraints.json`         | Ограничения технологических параметров                             | Ноутбук 1      |
| `param_constraints_2.json`       | Ограничения с метаданными (единицы измерения, описания параметров) | Ноутбук 2      |
| `mlcc_dataset2_all_columns.xlsx` | Исторические данные (1052 рецептуры)                               | Оба ноутбука   |
| `multi_multi_gb.pkl`             | Обученная multi-output модель Gradient Boosting                    | Ноутбук 1      |
| `pareto_front_nsga2.xlsx`        | Парето-фронт (100 оптимальных рецептур)                            | Ноутбук 2      |

### 3. Установка Ollama (для LLM-методов)

```bash
ollama pull qwen2.5:7b
ollama serve
```

### 4. Порядок запуска

1. **Получение_Парето_фронта_лучший_результат.ipynb**
   Выполняется многокритериальная оптимизация и формируется файл `pareto_front_nsga2.xlsx`.

2. **Получение_топ_3_рецептов.ipynb**
   Выполняется ранжирование Парето-фронта 10 различными методами и выбираются лучшие рецептуры.

# Описание ноутбуков

## Ноутбук 1: Получение Парето-фронта

### Цель

Найти 100 оптимальных рецептур методом NSGA-II.

### Основные этапы

* Загрузка обученной multi-output модели Gradient Boosting.
* Оптимизация параметров рецептуры по двум целевым функциям:

  * максимизация прочности (МПа);
  * максимизация удлинения (%).
* Использование генетического алгоритма NSGA-II:

  * размер популяции — 200 особей;
  * число поколений — 300.
* Формирование Парето-фронта из 100 недоминируемых решений.
* Сохранение результата в файл `pareto_front_nsga2.xlsx`.

### Требуемые файлы

* `multi_multi_gb.pkl`
* `mlcc_dataset2_all_columns.xlsx`
* `param_constraints.json`

---

## Ноутбук 2: Получение топ-3 рецептов

### Цель

Проранжировать решения Парето-фронта и выбрать лучшие рецептуры для заданного производственного сценария.

### Основные этапы

* Загрузка Парето-фронта, исторических данных и ограничений параметров.
* Формирование выборок:

  * **D_good** — успешные рецептуры;
  * **D_bad** — неудачные рецептуры.
* Вычисление компонентов оценки:

  * **HV** — гиперобъём;
  * **h(x)** — эвристика безопасности;
  * **P(x)** — система штрафов.
* Анализ текстового запроса технолога с помощью LLM для извлечения:

  * весов критериев;
  * мягких предпочтений по технологическим параметрам.
* Ранжирование рецептур десятью различными методами.
* Оценка качества по метрикам:

  * Historical F1@3;
  * Robustness;
  * Coverage.
* Формирование сравнительных таблиц топ-3 рецептур.

### Требуемые файлы

* `pareto_front_nsga2.xlsx`
* `mlcc_dataset2_all_columns.xlsx`
* `param_constraints_2.json`
* Ollama + `qwen2.5:7b`

# Реализованные методы ранжирования

| Метод           | Тип          | Описание                                                |
| --------------- | ------------ | ------------------------------------------------------- |
| HV-only         | Базовый      | Ранжирование только по гиперобъёму                      |
| h-only          | Базовый      | Ранжирование только по эвристике безопасности           |
| TOPSIS          | Классический | Расстояние до идеального решения                        |
| VIKOR           | Классический | Компромиссное ранжирование                              |
| PROMETHEE II    | Классический | Попарное сравнение альтернатив                          |
| HV+h+P          | Гибридный    | Гиперобъём + эвристика + штрафы                         |
| HV+h+P+LISTEN-T | LLM          | Гибридный метод с LLM-турниром                          |
| LISTENTOME      | LLM          | Турнирное ранжирование с использованием HV, h(x) и P(x) |
| LISTENTOME+     | LLM          | Автоматический подбор весов α и β с помощью LLM         |
| LISTENTOME++    | LLM          | Турнирная сетка на 16 участников                        |

# Производственные сценарии

Система протестирована на семи сценариях принятия решений:

1. Экономия бюджета
2. Стабильность для новичков
3. Зелёное производство
4. Золотая середина
5. Запах растворителей
6. Конкретные требования
7. Две смены

Для каждого сценария LLM автоматически извлекает веса критериев и предпочтения по технологическим параметрам, после чего выполняется подбор наиболее подходящих рецептур.
